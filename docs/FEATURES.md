# 当前功能全景

这份清单只记录当前仓库已经实现的能力，方便使用者判断项目是否适合自己的 xBloom 工作流，也方便贡献者做回归检查。

## 1. 桌面工作台

- 从豆仓选择豆子，或直接输入自由文本豆信息。
- 录入口味目标、风味标签、滤杯、参考链接、烘焙商参考方案与可用粉量。
- 联网调研开关可控；生成过程通过 SSE 逐步展示调研、推理、审查与最终配方。
- 结果区固定提供：上传到手机 xBloom App、冲煮引导、本地保存、返回修改输入。
- 配方编辑器允许继续修改粉量、总水、研磨度、每段注水、水温、流速、停顿、注水方式、振动、旁路水、颜色和段名。

## 2. 联网调研

调研按可用性组合以下来源：

1. 已登录的小红书 MCP：搜索笔记并读取正文；
2. SearXNG 聚合搜索；
3. Firecrawl 搜索与抓取；
4. 百度/Bing 等网页搜索兜底。

处理环节包括：

- 豆名、产地、处理法与自由文本拆分；
- 来源相关性过滤，拦截明显属于其他豆子的泛内容；
- V60、Kalita、Orea、Origami、Chemex、AeroPress 等滤杯信号识别；
- 标题、链接与正文近重复去重；
- 在线零结果、执行超时、服务离线三种状态区分；
- 提取水温、粉水比与研磨度信号，参与候选评分和一致性检查。

## 3. 多候选与自动审查

- 默认并行生成 3 个候选，可通过配置设置为 1–5。
- 七个评分维度：粉水比、水温×烘焙度、研磨×烘焙度、注水结构、总时长、口味偏好、调研贴合度。
- 一票否决项：目标路径校验、审查错误、分段总水不一致、云端粉水比不可达、旁路后比例越界。
- 平局顺序：总分、修正量、警告数、总时长与生成完成顺序。
- 低分方案会换查询角度、排除已用来源并重新调研；结果没有继续改善时及时收敛并说明。
- 最终方案经过规则审查，满足条件时触发一轮自动修正。

## 4. 配方模型与边界

- xDripper / 手冲路径；配方段数 1–6。
- 粉量、总水、水温、流速、停顿、研磨度与转速档位校验。
- 分段注水总和与 `grandWater` 一致。
- 云端和 BLE 使用不同的注水方式编码与研磨标尺映射。
- xBloom 云端粉水比 0.1 步进可达性检查与发布前自动对齐。
- 旁路水量、水温与最终粉水比守护。
- 振动时机、预磨粉模式、配方颜色和自定义段名。
- 内置 SCA 金杯、焙度参数带、名家方法与滤杯转换知识。

## 5. 曲线、步骤与冲煮引导

- ECharts 同屏显示注水、水温、流速与旁路曲线。
- 粉量、总水、粉水比、预计总时长等统计块。
- 每段注水参数卡与时间线。
- 方案选择理由和知识依据。
- 桌面冲煮引导：逐段推进、计时、暂停/继续和阶段提示。

## 6. 上传到手机 xBloom App

- 页面内手动登录自己的 xBloom 云端账号。
- 发布前预览实际云端字段与整数注水对齐结果。
- 创建新配方；从云端载入后可更新原配方。
- 查看自己的云端配方列表，载入、删除和打开分享链接。
- 上传完成后在手机 xBloom App 中刷新并使用。
- 全球区与中国区可配置。

## 7. 豆仓

- 豆名、烘焙商、产地、庄园、处理法、品种、烘焙度、风味、海拔和备注。
- AI 将文字标签内容整理成结构化字段并自动应用。
- 多级豆名匹配，减少重复空档案。
- 烘焙日期、建议养豆天数、峰值窗口、剩余克数与预计可冲次数。
- 冲煮后按实际粉量扣减库存，超扣时归零并提示。
- 结合适饮窗口、库存、历史反馈与风味轮换给出 Top 3 推荐。
- 从推荐卡或任意豆卡直达工作台。

## 8. 历史、反馈与版本

- 本地配方保存、删除、载入继续编辑。
- 按名称、豆信息、调研摘要、调整说明与杯测记录搜索。
- 收藏、有反馈、迭代版筛选。
- 1–5 星、味型标签与自由备注。
- 以旧配方和反馈为基础生成下一版，保留父子版本关系。
- 调参前后差异展示，回填反馈对应的新配方。
- 输入烘焙商参考方案时，可同时保留原版与 AI 改进版并展示变更依据。

## 9. 小红书账号与调研

- MCP 在线状态和账号登录状态分开显示。
- 页面内生成二维码，前端定时轮询扫码结果。
- 已登录时显示昵称；支持退出和切换账号。
- 扫码受限时支持粘贴浏览器 Cookie 串，并在导入后立即验证。
- 工具调用有探活与超时边界；失效状态回到登录入口。
- 会话文件仅保存在本机并被 Git 忽略。

## 10. 本机设置与运行

- 设置页填写 OpenAI 兼容 URL、主/备用模型和 Key。
- 保存后立即生效；“保存并测试”通过真实 `/chat/completions` 链路验证。
- Windows DPAPI 保护落盘 Key；API 响应不回传明文。
- Warm Paper / Espresso 双主题与持久化。
- PWA App Shell；接口请求不进入 Service Worker 缓存。
- Windows 一键安装、桌面快捷方式、隐藏启动、守护与停止脚本。
- 后端、前端、小红书 MCP 与可选 SearXNG 的健康检查和自恢复。

## 11. BLE 实验入口

- 探测本机 BLE 能力。
- 扫描并连接指定 xBloom 设备。
- 将内部配方编码为设备帧并按顺序下发。
- 支持停止指令和下发前确认。
- 该入口完整保留但默认折叠；常规使用建议走云端上传到手机 App。
