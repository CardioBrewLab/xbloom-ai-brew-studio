# xBloom 手冲知识库（内置参考资料）

> 本文件作为系统提示词的附录注入，为纯手冲配方生成提供参数依据。

## 1. SCA 金杯标准（Golden Cup）

| 指标                       | 目标区间                        | 说明                                                     |
| -------------------------- | ------------------------------- | -------------------------------------------------------- |
| 萃取率（Extraction Yield） | 18% - 22%                       | 低于 18% 欠萃（尖酸、单薄），高于 22% 过萃（苦涩、空洞） |
| TDS（浓度）                | 1.15% - 1.35%                   | 手冲常见目标；低于偏淡水感，高于偏重                     |
| 粉水比（手冲）             | 1:15 - 1:17                     | xBloom xdripper 默认 1:15.6                              |
| 冲煮水温                   | 90 - 95 ℃（标准），按烘焙度调整 | 设备上限 95℃                                             |
| 萃取均匀度                 | 注水图案与流速控制              | 绕圈/螺旋提升均匀度                                      |

## 2. 名家方法论参数表

### Kasuya 4:6 分段法（Tetsu Kasuya，2016 WBrC 冠军）

- 总水量 = 40% + 60%：前 40% 定酸甜，后 60% 定浓度。
- 前 40% 拆两段：第一段较小 → 偏甜；第一段较大 → 偏酸。
- 后 60% 拆 1-3 段：段数越多浓度越低、越清爽。
- 参考：20g 粉 / 300ml 水 / 92℃ / 中细研磨；每段间停顿 45s 左右。
- 映射 xBloom：pours 4-5 段，闷蒸段 pausing 40-45s。

### Scott Rao 浸泡式手冲

- 粉水比 1:16；闷蒸 3 倍粉量，45s。
- 一次性大注水 + 轻微绕圈，总时长 2:30-3:00。
- 追求高萃取均匀度，避免通道效应。
- 映射 xBloom：2-3 段，大 volume + circular，节奏平稳。

### James Hoffmann V60 一刀流

- 粉水比约 1:16.7；映射 xBloom 时取就近可达组合：**15g → 249ml（1:16.6）或 255ml（1:17）**，勿取 250ml（15×16.7=250.5≠250，官方云端按 0.1 步进粉水比校验，不可达）。
- 闷蒸 2 倍粉量 45s；主注水到 60% 时轻微晃杯；总时长 2:00-3:00。
- 浅焙可顶格 95℃（xBloom 上限 95℃），深焙降至 85-90℃。
- 映射 xBloom：2-3 段，第一段闷蒸，第二段主体 circular，尾段 center 收尾。

## 3. 烘焙度 → 参数映射经验表

| 烘焙度                 | 水温（℃） | grinderSize（云端标尺 40-120，越小越细） | rpm      | 节奏（pausing）   | 风味目标               |
| ---------------------- | --------- | ---------------------------------------- | -------- | ----------------- | ---------------------- |
| 浅焙（Light）          | 92 - 95   | 55 - 70（偏细，≈C40 16-22 格）           | 90 - 110 | 紧凑，闷蒸 30-40s | 明亮酸质、花果香、干净 |
| 中浅焙（Medium-Light） | 90 - 93   | 60 - 74（≈C40 18-23 格）                 | 80 - 100 | 闷蒸 35-45s       | 酸甜平衡、风味清晰     |
| 中焙（Medium）         | 88 - 92   | 64 - 78（≈C40 20-25 格）                 | 80 - 90  | 均衡，40-50s      | 甜感、圆润、醇厚       |
| 中深焙（Medium-Dark）  | 85 - 90   | 70 - 80（≈C40 22-25 格）                 | 70 - 80  | 放慢，45-60s      | 醇厚、低酸、避免杂味   |
| 深焙（Dark）           | 80 - 88   | 76 - 80（偏粗，≈C40 24-25 格）           | 60 - 70  | 慢冲，50-70s      | 避免苦涩，顺滑、可可调 |

内部与云端统一使用 40-120 标尺；BLE 设备使用 1-80 标尺，下发时按端点对齐线性映射。两者是不同单位，不对数值直接取交集。

经验规则：

- 想要更明亮/更酸：水温 ↑、研磨 ↓（更细）、段间停顿 ↓、多段拆分。
- 想要更醇厚/更干净：水温 ↓、研磨 ↑（更粗）、段间停顿 ↑、减少段数。
- 想要更甜：前 40% 水量减小（Kasuya）、中段流速放缓（flowRate 靠近 3.0）。
- 水流选择：闷蒸用 center 或小圈 circular；主体段 circular；大水量收尾段 spiral 铺匀；最后一段 center 稳水。

## 4. 处理法微调经验

| 处理法          | 倾向调整                                                                              |
| --------------- | ------------------------------------------------------------------------------------- |
| 水洗（Washed）  | 标准参数；突出干净与酸质，水温可偏上限                                                |
| 日晒（Natural） | 研磨略粗一档、水温略降 1-2℃，避免发酵杂味                                             |
| 蜜处理（Honey） | 介于两者之间；注重甜感，中温慢冲                                                      |
| 厌氧/特殊发酵   | 水温降 2-3℃（命中特殊处理法硬约束时以 ≤92℃ 为准，不折中）、节奏放缓，避免刺激性发酵味 |

**与烘焙商参数冲突时的裁决（任务 #30）**：烘焙商豆卡参数与上表经验规则冲突时（典型：厌氧/特殊发酵给了 ≥93℃ 高温），优先遵循处理法规则做小幅修正：厌氧/特殊发酵目标水温 89-92℃（在烘焙商水温基础上下调 1-3℃）；大幅冲突（≥5℃ 或方向相反）时取折中值（命中特殊处理法硬约束时以 ≤92℃ 为准，不折中）。无冲突时烘焙商的时间轴/比例/研磨应忠实复刻。修正需在 reasoning 中说明（如“烘焙商建议 94℃，因厌氧处理调整为 91℃”）。

**特殊处理法降温硬约束（任务 #35）**：**厌氧、冷浸、浸泡发酵类蜜处理（含 SFW、submerged、冷水漫清、葡萄干蜜/长时间发酵蜜处理等标注）的起步水温不得超过 92℃**（目标区间 89-92℃）。该硬约束优先于烘焙商豆卡水温与品种/极浅烘的高温倾向；**92℃ 是绝对上限，不存在突破上限的折中（见系统提示词第 3 节裁决条款 3）**：烘焙商水温高于 92℃ 时直接降至 89-92℃ 并在 reasoning 说明。

## 5. 常见场景配方骨架（xdripper）

- **明亮果酸浅焙（如埃塞俄比亚）**：15g 粉 / 234ml 水（1:15.6）/ 93-95℃ / grinder 58-66（≈C40 17-20 格）/ rpm 100 / 3-4 段（Kasuya 或 Hoffmann 骨架）。
- **均衡日常中焙**：15g / 234ml / 90℃ / grinder 64-70（≈C40 20-22 格）/ rpm 90 / 3 段。
- **低苦深焙**：15g / 234ml / 84-86℃ / grinder 74-80（≈C40 23-25 格）/ rpm 70 / 2-3 段，尾段 pausing 加长；首段 vibBefore 整平粉床。
- **浅焙浓缩 + bypass**：15g / 180ml 滤杯水（1:12）/ 94℃ / grinder 55-60（浓缩冲法偏细，≈C40 16-18 格）/ 3 段 + bypassEnabled、bypassVolume 45ml、bypassTemp 85℃（最终比例 15:1），香气层次更突出。

## 6. 旁路水（Bypass）技法

原理：滤杯内只过一部分水完成萃取，萃出液浓度高、风味物质集中；再用滤杯外的热水稀释到目标浓度。
稀释不额外增加过萃（苦/涩物质不会被多萃取），因此可以在“高萃取率 + 正常浓度”区间工作，酸甜与香气更清晰。

| 目标             | 建议做法                                           |
| ---------------- | -------------------------------------------------- |
| 浅焙放大花果香   | 滤杯水 1:10-1:13 浓缩冲，bypass 补到最终 1:15-1:16 |
| 降浓度不拉长萃取 | 保持原滤杯参数，bypass 补 10-40ml                  |
| 大杯量（>300ml） | 滤杯内控制在 250-300ml，剩余用 bypass 补足         |

经验规则：

- 最终粉水比（grandWater + bypassVolume）/ dose 控制在 12-20；常见 14-16。
- bypassTemp 80-90℃：太低会把整杯拉温，太高无必要（不接触粉）。
- bypassVolume 5-100ml 整数；超过 50ml 时建议略提高滤杯内萃取强度（更细/更热）避免寡淡。
- 启用 bypass 时，grandWater 仍须等于各段 volume 之和（bypass 不计入分段注水）。

## 7. 振动搅拌（Agitation / vibBefore / vibAfter）

xBloom 每段可选注水前/后振动，作用与传统手冲的“晃杯/拨粉”等价：

| 时机                | 作用                       | 适用场景                           |
| ------------------- | -------------------------- | ---------------------------------- |
| 注水前（vibBefore） | 整平粉床、打散布粉结块     | 首段前；深焙细粉、静电结块、大粉量 |
| 注水后（vibAfter）  | 均匀浸润、排气、消除干粉团 | 闷蒸段后；浅焙高水温快冲           |

经验规则：

- 常规配方不开振动（保持干净口感）；只在布粉不均/结块/闷蒸不均问题时针对性开启。
- 每段都开会过度扰动粉床，增加杂味与浑沌感，最多 1-2 段使用。
- 深焙 + 细研磨组合最容易受益于首段 vibBefore。
- 云端字段 isEnableVibrationBefore/After（1 开 / 2 关）会保留前/后时机。当前实验 BLE LOAD 协议只识别“螺旋+搅拌”布尔修饰（agit=0x02），因此直连时前、后或前后都会折叠为一次搅拌；需要精确保留时机时使用手机 xBloom App 上传链路。

## 8. 手磨刻度换算（Comandante C40 ↔ xBloom）

方向规则：**C40 格数与 xBloom 云端 grinderSize 同向**——数值越小越细、越大越粗。

换算公式（依据 xBloom 官方帮助中心 C40 换算表推导）：

- 正向：grinderSize(cloud) = clamp(round(10 + 2.75 × C40格数), 40, 120)
- 反向：C40格数 = clamp(round((cloud − 10) / 2.75), 0, 40)

官方锚点表：

| C40 格数    | 11  | 15  | 18  | 22  | 26  | 30  | 33  | 36  | 40  |
| ----------- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| grinderSize | 40  | 51  | 59  | 70  | 81  | 92  | 100 | 109 | 120 |

- 22 格 ≈ 70（约 600µm）为官方推荐校准点。
- 烘焙商常见手冲区间：C40 20-25 格 ↔ grinderSize 65-79。
- 用户只报“C40 N 格”时直接按上述公式换算；换算结果超出 40-120 时按端点钳位。BLE 下发另行映射为设备 1-80。

## 9. xBloom 官方滤杯特性与他滤杯参数移植（任务 #32/#125）

**滤杯结构事实（关键前提）**：xBloom 官方滤杯（xDripper 一次性杯 / Omni Dripper）是**平底 + 底部限流孔**结构（官方：设计灵感来自 Kalita Wave），**不是 V60 锥形**。排水由底部孔限流而非研磨度主导：接触时间更长、粉床平坦均匀、容错高于 V60。

烘焙商豆卡/冲煮建议或联网调研来源标注为其他滤杯/手冲器具参数时，按下表向 xBloom 官方滤杯移植修正，并在 reasoning 中写明「烘焙商/调研来源为 X 滤杯参数，已按 xBloom 官方滤杯修正研磨/水温…」式的说明。**段数、比例、闷蒸、停顿节奏忠实复刻，不因滤杯不同而重建骨架**。

### 9.1 V60（锥形）→ xBloom 官方滤杯

| 维度      | 移植规则                                                                               | 机理                                     |
| --------- | -------------------------------------------------------------------------------------- | ---------------------------------------- |
| 研磨      | 维持原值或略粗（云端刻度 +2~4，数值越大越粗；浅焙区间 55-70）。**禁止照搬 V60 偏细值** | 平底限流延长接触时间，细粉易过萃发苦发涩 |
| 水温      | 烘焙商水温先降 1-2℃（浅焙尤其），实际冲煮出现尖酸再回升                                | 平底容错高、萃取效率略低，略降防过萃     |
| 比例/骨架 | 比例、闷蒸、分段结构忠实复刻；闷蒸通则 2-3×粉量、30-45s                                | —                                        |
| 注水图案  | 默认 spiral；平底杯防中心通道可用 circular；center 偏浸泡、body 更厚                   | 平底粉床平坦均匀，注水图案容错更高       |
| 总时长    | 比 V60 预期长 15-30s 属正常；>3:00 才考虑调粗/减段                                     | 机器流速约 3-3.5ml/s、无高冲搅拌         |

### 9.2 Kalita Wave → xBloom 官方滤杯

Kalita Wave 与 xBloom Omni Dripper 同为平底+波形/平底滤纸+底部限流孔结构，**基本直接复用**：

| 维度      | 移植规则            | 机理                 |
| --------- | ------------------- | -------------------- |
| 研磨      | 维持原值或略粗 +0~2 | 结构同构，研磨差异小 |
| 水温      | 维持或微降 0~1℃     | 萃取特性接近         |
| 比例/骨架 | 忠实复刻            | —                    |

### 9.3 Orea（平底快流速）→ xBloom 官方滤杯

Orea 为平底但流速更快（底部孔径/数量更大），需补偿快流速带来的萃取不足风险：

| 维度      | 移植规则                      | 机理                         |
| --------- | ----------------------------- | ---------------------------- |
| 研磨      | 维持或略细 -1~2（补偿快流速） | 流速快→接触时间短→需略细补偿 |
| 水温      | 维持                          | —                            |
| 比例/骨架 | 忠实复刻                      | —                            |

### 9.4 Origami → xBloom 官方滤杯

Origami 可配锥形滤纸或波形滤纸，视滤纸类型而异：

| 维度      | 移植规则（波形滤纸）   | 移植规则（锥形滤纸）      | 机理                          |
| --------- | ---------------------- | ------------------------- | ----------------------------- |
| 研磨      | +0~2（同 Kalita 同构） | +1~2（同 V60 但幅度更小） | 波形滤纸同 Kalita；锥形同 V60 |
| 水温      | -0~1℃                  | -0~1℃                     | 幅度小于 V60                  |
| 比例/骨架 | 忠实复刻               | 忠实复刻                  | —                             |

### 9.5 Chemex → xBloom 官方滤杯

Chemex 滤纸更厚（20-30μm）、流速更慢、萃取更充分，移植时需明显调粗补偿：

| 维度      | 移植规则                           | 机理                                  |
| --------- | ---------------------------------- | ------------------------------------- |
| 研磨      | +3~5（明显略粗，补偿厚滤纸高萃取） | 厚滤纸+慢流速→萃取效率高→需调粗防过萃 |
| 水温      | -1~2℃                              | 同向降湿防过萃                        |
| 比例/骨架 | 忠实复刻                           | —                                     |
| 总时长    | 可能比 Chemex 原方案缩短           | xBloom 底部孔限流但无厚滤纸           |

### 9.6 AeroPress → xBloom 官方滤杯

AeroPress 机理完全不同（浸泡+按压，非重力渗滤），**不可机械转换**：

| 维度      | 移植规则                                     | 机理                     |
| --------- | -------------------------------------------- | ------------------------ |
| 研磨      | **不可转换**——按 xBloom 官方滤杯经验重新设计 | 浸泡 vs 渗滤机理根本不同 |
| 水温      | 仅作大方向参考                               | —                        |
| 比例      | 仅作大方向参考                               | —                        |
| 段数/节奏 | **不可转换**——按 xBloom 官方滤杯经验重新设计 | —                        |

> **注意**：AeroPress 来源的参数仅作为该豆的冲煮大方向参考（如水温区间、粉量范围），研磨度和分段节奏须按 xBloom 官方滤杯特性重新设计，不可照搬。

机器注水限制与时长预期（通用）：

- 机器流速约 3-3.5ml/s、无高冲搅拌，同配方萃取可能略低于手冲手注；萃取不足的补偿手段是**加脉冲段数、缩短段间 pausing**，而不是一味调细。
- 总时长比原滤杯预期长 15-30s 属正常（Kalita/Orea 除外，同构差异小）；>3:00 才考虑调粗/减段。

## 10. 12g / 低粉量冲煮（任务 #32）

- 12g 在官方支持范围内（Omni Dripper 2 官方推荐 5-18g）；云端官方配方清一色 15g 是 Original 机型 / xPod 预封装的产品锁，**不是冲煮物理限制**——不要因“官方都是 15g”而劝用户改粉量。
- 平底杯对低粉量天然友好（粉床摊平、通道风险低于锥形），无需特殊警告。

**12g 配方模板**（**L6 模板：本表所有数值仅当无烘焙商方案时生效**；有烘焙商方案时以其时间轴为准——段数、累计比例、停顿逐段复刻，本模板只用于研磨/流型等细节微调）：

| 维度            | 建议                                                                                                                    |
| --------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 总水 grandWater | 180-198ml（1:15-1:16.5；取值须满足 0.1 步进粉水比可达：12×16.7=200.4≠200，故勿取 200ml；推荐 198ml=1:16.5、192ml=1:16） |
| 闷蒸            | 24-30g（2-2.5×粉量）、30-45s（**闷蒸硬下限：pausing ≥ 30s，12-20g 粉量推荐 30-45s，低于 30s 视为闷蒸不足**）            |
| 分段            | 2-3 段小水量脉冲                                                                                                        |
| pattern         | spiral 或 circular（避免 center 大流量冲击薄粉床）                                                                      |
| 目标总时长      | 1:45-2:30                                                                                                               |

**12g 研磨规则**（注意与 §9 方向相反，勿混淆）：相对同豆 15g 配方略细一档，补偿薄粉层快排水；但这是相对 15g 版本的小幅补偿，仍不得照搬 V60 偏细值。以总时长为判定窗：<1:30 调细、>2:45 调粗。

## 11. 品种专项（任务 #35）

品种倾向作为 §3/§4 处理法与焙度规则之上的微调依据；**品种倾向不得覆盖特殊处理法降温硬约束**（见 §4）。

### Chiroso（哥伦比亚）

- 水温 90-92℃；研磨比一般同焙度浅焙**稍粗**（云端刻度 +2~3，数值越大越粗）。
- 粉水比 1:15-1:16；风味目标突出花香与层次，节奏可稍放缓。

### 埃塞 JARC 原生种 74158 / 74153

- 风味取向：花香、柑橘、莓果；常见于西达摩等产区。
- 极浅烘（Agtron 95+）：水温顶格 93-95℃、研磨偏细，托出花香与明亮酸质。
- **若为冷浸/SFW 等特殊发酵处理：必须按 §4 特殊处理法降温硬约束执行（起步水温 ≤92℃），品种高温倾向让位于处理法规则**，并在 reasoning 中说明。

### 肯尼亚 SL28 / SL34

- 水温 91-94℃；中细研磨但**控制细粉**（不宜逼近浅焙研磨下限），细粉多时平底滤杯易堵塞：避免大圈高频搅动、保持干净利落的排水。
- 风味取向：黑加仑/多汁明亮酸质；围绕酸质清晰度调水温与节奏。
