# xBloom AI Brew Studio v0.1.1 发布终审

日期：2026-08-11

范围：MAX 多候选、Cloudflare 常在线版、Windows 跨电脑安装、登录与配置隔离

结论：PASS（独立代码审查无遗留项）

## 根因与处理

| 问题                                | 根因                                                                         | v0.1.1 处理                                                                                      |
| ----------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 两个候选分数相同，难以判断是否重复  | 原界面只突出总分，没有展示足够的可执行参数；去重判定也过度依赖完整序列化指纹 | 候选需至少有两项实质参数差异；重复槽位单独重生成；同分时标明“同分但参数不同”，并展开完整参数摘要 |
| 第三个候选偶发 `fetch failed`       | 单次模型请求的瞬时网络错误直接终止该候选，错误原文又直接进入界面             | 每个候选对瞬时传输错误自动重试一次；保留既有 3→2→1 降并发；对用户返回分层且脱敏的失败原因        |
| Cloudflare 候选与桌面契约不完全一致 | 云端评分、选择、错误分类及 SSE 字段曾是简化实现                              | 云端补齐三方向、确定性 seed、去重重生成、七维连续评分、稳定决胜和桌面兼容的 SSE 契约             |
| 新电脑安装在 exFAT 盘失败           | npm workspaces 需要目录链接，而 Windows exFAT 不支持相应重解析点             | 安装器按卷格式选择依赖安装方式；exFAT 使用实体 shared 包同步，NTFS/ReFS 继续采用 workspace 链接  |
| 重部署可能改变浏览器拥有的数据身份  | 部署脚本过去会重复生成会话签名密钥                                           | 仅在云端尚无 `APP_SESSION_SECRET` 时创建；后续部署保留原密钥                                     |

## 四视角审查

### 1. 手冲咖啡从业者

- 候选摘要覆盖实际执行链：豆量、总水量、旁路水、有效粉水比、研磨、转速、每段水量/温度/流速/停顿/注水模式/振动。
- 粉类输入为预磨粉时，界面显示“预磨粉（机器跳过研磨）”，隐藏不会执行的研磨刻度与转速。
- 候选差异按可执行参数计数，展示名或派生字段变化不再伪装成新方案。

### 2. xBloom 第三方设计者

- 产品主链保持“电脑生成与复核 → xBloom 官方云端 → 手机 xBloom App 使用”。
- 未改变 xBloom、小红书登录文件及已有本机会话；开源安装者首次启动后配置自己的账户。
- 云端版与桌面版的候选事件契约一致，仍由现有前端组件消费。

### 3. 手冲咖啡爱好者

- 相同总分现在会直接展示参数区别，不再要求用户猜测评分背后的方案差异。
- MAX 三个方向分别偏稳定均衡、清晰层次、甜感醇厚；发现近重复时自动补生成该槽位。
- 单个候选遭遇短暂网络波动时会自动重试，其余已成功候选继续保留。

### 4. 代码审核者

- 本地与云端均以“至少两项实质参数差异”作为候选去重门槛。
- 网络错误识别支持嵌套 cause、超时、常见 Undici 传输错误与临时 5xx，重试等待可响应 AbortSignal。
- Cloudflare 评分为七维连续加权分，使用原始质量分与稳定指纹打破同分，不固定偏向候选 1。
- Windows 安装、构建、运行和停止脚本均覆盖含空格路径与 exFAT 安装盘。
- 发布扫描确认仓库不含 `.env`、会话、Cookie、运行时目录或常见明文密钥模式。

- Cloudflare 常在线版由 Worker、静态资源和 D1 提供，本机关闭后仍保持在线。

- 桌面完整版保留所有本地能力；常在线版聚焦生成、候选对比与配方工作流。
