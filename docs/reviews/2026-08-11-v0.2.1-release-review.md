## 审查轮次

### Round 1

独立 reviewer 报告 3 个 medium 和 2 个 low：

| 严重度 | 问题                                                        | 修复                                                                                                    |
| ------ | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| medium | exFAT/FAT 不支持 NTFS DACL，小红书助手启动可能中断          | 仅在 NTFS/ReFS 收紧 ACL；exFAT/FAT 保留重解析点校验并给出明确提醒；干净安装新增运行目录准备检查         |
| medium | 可信 EdgeOne 请求只校验共享密钥，跨源写请求可获得 CSRF 豁免 | EdgeOne 入口先校验 Origin；Worker 再校验 Origin、`x-forwarded-host` 与 HTTPS 协议，加入伪造代理回归测试 |
| medium | 文档、tag 与 package 版本可能不一致                         | README/PUBLISHING 更新到 0.2.1；Release workflow 强制校验 `v<package.version>`                          |
| low    | 隐私门禁未覆盖大陆手机号和纯数字 GitHub 账号 URL            | 新增对应扫描规则并扩展 Markdown/查询/锚点边界                                                           |
| low    | 未配置模型时的提示没有区分 Hosted 与本地版                  | Hosted 提示先登录，本地版提示从右上角打开设置                                                           |

### Round 3

exFAT 全量复测暴露出测试夹具关闭旧 mock 服务时未等待连接彻底结束的竞态。该问题只位于测试生命周期，不涉及产品请求路径；现已统一等待 HTTP 服务完成关闭、主动收口 keep-alive 连接并恢复全部 LLM 测试配置。稳定性压测还发现旧 DPAPI 用例把三位数字 ID 当作密文子串进行断言，随机 Base64 偶遇相同数字时会误报；现改为检查敏感字段未以明文 JSON 结构落盘。定向候选测试 20/20、完整 server 套件连续 5 轮 556/556，随后全量门禁和 exFAT 干净安装均通过。
